# Flet Patch For Nuitka

Этот файл нужен, чтобы не хранить `.venv` в git, но при этом не потерять
правки, которые заметно ускоряют анализ Nuitka.

## Что делает патч

Патч из [flet-nuitka-lean.patch](/f:/Proga/DataTransferApp/patches/flet-nuitka-lean.patch:1):

- облегчает `flet/__init__.py`, чтобы импорт подмодулей не тянул весь пакет;
- убирает runtime-импорт огромных enum-иконок из `flet/core/types.py`;
- уменьшает количество модулей, которые Nuitka обязан анализировать.

Это особенно полезно, если проект:

- не использует `from flet import ...`;
- не использует встроенные `ft.icons` / `ft.Icons`;
- рендерит иконки своими SVG/PNG ассетами.

## Как применять

После создания `.venv` и установки зависимостей:

1. Найдите папку `site-packages/flet`.
2. Примените изменения из `patches/flet-nuitka-lean.patch` вручную
   или своим patch-инструментом.

Примерно это должно попасть в:

- `.venv/Lib/site-packages/flet/__init__.py`
- `.venv/Lib/site-packages/flet/core/types.py`

## Важно

- Эти правки относятся к локальному окружению сборки, а не к коду приложения.
- `.venv` коммитить не нужно.
- После переустановки окружения патч надо накатывать заново.
- Если начнёте снова использовать встроенные Flet-иконки, патч лучше пересмотреть.

## Зачем это держать в репозитории

Чтобы было видно:

- почему сборка ускорялась;
- какие именно файлы в `flet` были изменены;
- как восстановить оптимизированное окружение на другой машине.
